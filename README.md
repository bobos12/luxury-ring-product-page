# Luxury Ring Product Page

A fully responsive, premium jewelry product page featuring an interactive product gallery, variant selection, and a dynamic shopping cart built with **HTML**, **CSS**, and **JavaScript**.

## Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile screens.  
- **Interactive Product Gallery:** Main image with clickable thumbnails.  
- **Variant Selection:** Users can choose color and size with visual feedback.  
- **Dynamic Cart:** Add multiple items, track quantity, and see live cart updates.  
- **Related Products Section:** Showcases additional items to encourage browsing.  
- **Accessible & Semantic HTML:** Proper ARIA roles and semantic markup.  

## Tech Stack

- **HTML5** — Semantic structure  
- **CSS3** — Flexbox & Grid layout with design tokens  
- **JavaScript (ES6 Modules)** — DOM manipulation, state management
